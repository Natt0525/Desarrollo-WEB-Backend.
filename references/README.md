# Referencias del proyecto

Esta carpeta reúne material de consulta y evidencia que no se importa directamente desde la aplicación.

- `visual-style/`: imágenes usadas para definir la dirección visual.
- `ifixit-galaxy-s10/`: referencias técnicas y atribución de la guía de desmontaje.
- `test-evidence/`: capturas aportadas durante revisiones visuales y funcionales.
- `source-documents/`: documentos originales usados para comprender el flujo del taller.

Los archivos se conservaron sin modificar; únicamente se reorganizaron para que su propósito sea evidente.
